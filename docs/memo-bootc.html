Mémo bootc — commandes quotidiennes

Image Fedora 44 bootc + CachyOS + Nvidia 615. Système en lecture seule sur /usr : on ne fait plus dnf install au quotidien, on met à jour l'image.

1. État et mises à jour système

sudo bootc status

Usage : voir le déploiement actuel et celui en attente. Résultat : image active, version, rollback dispo.

sudo bootc update

Usage : télécharger et préparer la nouvelle image. Résultat : appliquée au prochain reboot, l'ancienne reste pour rollback.

sudo bootc upgrade

Usage : alias de update. Résultat : idem.

sudo bootc rollback

Usage : revenir au déploiement précédent. Résultat : actif après reboot, sans perdre de données /home.

sudo bootc usr-overlay

Usage : rendre /usr modifiable pour TESTER un paquet. Résultat : perdu au reboot, à intégrer au Containerfile si concluant.

2. Build image + ISO (recette)

./build.sh localhost/mon-bootc:latest 2>&1 | tee build.log

Usage : construit l'image puis l'ISO Anaconda dans ./output. Résultat : output/*.iso interactive.

sudo podman images

Usage : lister les images locales. Résultat : vérifie que ton tag existe avant le build ISO.

3. Flatpak et firmwares

sudo ./install-flatpaks.sh

Usage : installe Bazaar, Extension Manager, Gearlever, Heroic, ProtonUp-Qt. Résultat : 5 apps Flathub système.

flatpak update

Usage : mettre à jour les apps. Résultat : apps à jour sans toucher l'image.

fwupdmgr get-updates && fwupdmgr update

Usage : firmwares matériels. Résultat : BIOS, SSD, dock à jour.

4. Snapper et btrfs

sudo snapper -c root create-config / ; sudo snapper -c home create-config /home

Usage : une seule fois au 1er boot. Résultat : snapshots auto pre/post via dnf5.

sudo snapper ls ; sudo snapper -c home ls

Usage : lister les snapshots. Résultat : paires pre/post avant chaque transaction.

sudo btrfs scrub start -B /

Usage : vérification checksums manuelle. Résultat : erreurs détectées tôt, timer mensuel déjà actif.

5. Gaming

sudo WITH_GAMING=1 ./install-flatpaks.sh

Usage : stack gaming hors image (Steam, Heroic, Lutris, ProtonUp-Qt, Goverlay, MangoHud, vkBasalt) en Flatpak persistant. Résultat : jeux sans regonfler l'ISO.

gamemoderun mangohud %command%

Usage : options de lancement Steam. Résultat : governor perf + overlay FPS pendant le jeu.

flatpak run net.davidotek.pupgui2

Usage : ProtonUp-Qt. Résultat : installe GE-Proton pour Steam/Lutris/Heroic.

vulkaninfo | grep driverName ; gamemoded -t

Usage : vérifier GPU 4070 et GameMode. Résultat : driver Nvidia actif (post-install), daemon OK.

6. Disques

lsblk -f

Usage : identifier disques et filesystems AVANT toute action. Résultat : jamais de format sur le mauvais disque.

sudo setup-second-disk.sh

Usage : monte le 2e NVMe en /mnt/data via fstab UUID. Résultat : auto-monté au boot, plus de mot de passe. Ne formate jamais.

7. Dépannage

mokutil --sb-state

Usage : état Secure Boot. Résultat : doit être désactivé ou clé MOK enrôlée, sinon kmods Nvidia/DKMS rejetés.

journalctl -b -p err

Usage : erreurs du boot actuel. Résultat : piste driver/service en cause.

Grub → déploiement précédent

Usage : au boot, choisir l'ancien déploiement. Résultat : système qui marche, puis bootc rollback pour fixer.

Clé USB install (RTX) : au menu GRUB, E, ajouter nomodeset, Ctrl+X

Usage : erreurs gsp/nouveau au boot bare metal (RTX 4070 non gérée par nouveau). Résultat : affichage simple, Anaconda voit les disques.

8. Re-baker un pilote (sans réinstaller)

sudo bootc switch --transport containers-storage localhost/mon-bootc:latest

Usage : après rebuild avec le driver remis dans le Containerfile. Résultat : /etc et /var conservés, seul /usr remplacé. Reboot derrière.
